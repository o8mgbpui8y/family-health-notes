# 这个暑假割还是不割？

> 更新时间：2026-09-16 (UTC+8)

“你家娃割了吗？”

“不割会不会影响发育啊？”

.....

每逢假期，关于那个“割不割”的话题，总是困扰着家长。各大医院里，小儿外科也成了大热门，日均手术比平时多了2-3倍。娃要不要割包皮？啥时候割？我们来帮你解答。

**什么是包皮过长、包茎？**

**包皮过长：**是指阴茎皮肤包裹龟头，使龟头不能完全外露。其中又可分为真性包皮过长和假性包皮过长。真性包皮过长是阴茎勃起后龟头也不能完全外露；假性包皮过长是指平时龟头不能完全外露，但在阴茎勃起后龟头则可以完全外露。

**包茎：**是指包皮完全包裹龟头，龟头任何时候都不能外露。

**包皮包茎的危害**

易得泌尿感染性疾病：由于包皮垢等沉积物的作用，可引发包皮炎、龟头炎、尿道炎、生殖器疣、疱疹等感染性疾病。

**青春期时：**如果存在包皮过长、包茎等会阻碍阴茎正常发育，阴茎明显小于常人。

**成年后：**过长的包皮内积存大量包皮垢，包皮垢中饱含各类细菌，会造成男性性方面的疾病，及配偶相关妇科炎症。 

**有致癌的危险:**包皮垢炎症的反复刺激是阴茎恶变的主要原因。临床资料显示，包皮过长，特别是包茎患者，阴茎病变的发病率较高。

割包皮的手术指征，除了参考包皮长度之外，更多的是看临床症状。一般来说，**有以下四种情况之一是建议手术的：**

**01病理性包茎：**儿童4-6周岁以前，包皮不能翻起是正常的，属于生理性包茎。如果6周岁后包皮口非常狭小，还不能翻起，就属于病理性包茎了，建议手术。

**02包皮明显过长：**6周岁后，儿童包皮长出部分超过阴茎体的1/3，这样的情况也建议手术。

**03感染：**如果包皮、龟头反复红肿感染，就算年龄不满3周岁，也一定要尽早手术。
**04疤痕性包茎：**这些疤痕其实是之前反复感染发炎引起的，也建议尽早手术。

**发现小儿包茎家长怎么办？**

家长发现孩子有包茎后，先把孩子带到医院，听取医生的专业建议，暂时不做手术的孩子，家长要密切观察孩子是否有尿道炎症、包皮炎及其他伴随症状；需要手术治疗的包茎患儿要及时进行手术治疗，避免造成阴茎发育异常、包皮粘连、包皮龟头炎等问题；家长应高度重视孩子的包茎问题，对包茎手术进行充分了解后，再接受治疗 。
